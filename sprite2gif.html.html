📖 使用说明（点开查看）
① 三步上手：拖入图片（或点击选择 / Ctrl+V 粘贴）→ 看预览并点缩略图选择动作 → 点「🎬 生成 GIF」再下载。
② 一张图多个动作：识别为网格后，点行（列）缩略图切换；「下载全部」一键导出每个动作。
③ 多张图一起处理：一次拖入多张图片，点顶部「📦 批量」按钮逐个导出。
④ 常用调整：动作太快/太慢→调「帧延时」；小图模糊→「放大倍数」4~6x；背景默认「智能去背」自动抠透明底。
⑤ 识别不对？试试「快捷预设」（如 3列×4行），或手动修改行数/列数/帧数，看①区预览核对。
⑥ 隐私：全程本机处理，图片不上传、可离线使用。
⑦ 手机使用：点「📁 选择图片」从相册选图即可。
华为/鸿蒙手机：若在微信里点不动→右上角「···」→用「华为浏览器」打开；或先把文件存到「文件管理→下载」目录再用浏览器打开（如遇页面异常，可把文件名改成英文如 sprite2gif.html 再试）。选了大照片请等几秒（会自动压缩，属正常）。
⚠ 页面脚本未能正常加载：可能是浏览器版本过旧或 JavaScript 被拦截。请尝试用 Chrome / Edge / Safari 打开本文件；若仍不行，请把手机型号与浏览器名称告诉工具作者。
